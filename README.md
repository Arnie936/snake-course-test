# Simple Snake Game in Python

This is a classic Snake game built using the `pygame` library.

## Prerequisites

- Python 3.x installed on your system.
- `pygame` library.

## Setup Instructions

1. **Install Pygame**:
   Open your terminal or command prompt and run:
   ```bash
   pip install pygame
   ```

2. **Run the Game**:
   Navigate to the directory where `snake.py` is located and run:
   ```bash
   python snake.py
   ```

## Controls

- **Arrow Keys**: Move the snake (Up, Down, Left, Right).
- **C**: Play again after a "Game Over".
- **Q**: Quit the game.

## Gameplay
- Eat the **green block** (food) to grow and increase your score.
- Avoid hitting the walls or your own tail!
